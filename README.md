# Recently Funded Startups (No Auth)

A simple app to view recently funded startups.

## Features

- No authentication or login
- Public API endpoint: `/api/startups`
- Search and filter by sector
- Mobile-friendly UI

## Tech Stack

- Node.js + Express
- Plain HTML/CSS/JavaScript frontend
- JSON file as data source

## Run Locally

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the app:

   ```bash
   npm start
   ```

3. Open:

   ```
   http://localhost:3000
   ```

## Data

Startup records are stored in:

- `data/startups.json`

You can replace this with your own data feed later, and the app UI will continue to work.
